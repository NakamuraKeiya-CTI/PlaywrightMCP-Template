# 概要

- このプロジェクトはPlaywright MCPを利用した結合テスト自動化の操作感を検証するためのもの
- フロントだけで完全に独立して動作する、簡易なReactで作成してある

## clone後の操作

1. `npm install`をプロジェクトルートフォルダで実行
2. `npm run dev`でローカルでReactを起動
3. 下記のようなプロンプトをClaudeCodeで実行する

```txt
playwright mcpを使用して、結合テストを実行してください。条件は下記の通り。

- `PlaywrightMCP-Template\docs\結合テスト\_テストマスタ`の`_テストマスタ`フォルダを`PlaywrightMCP-Template\docs\結合テスト`配下に複製して今回分のテストフォルダを作成してください。その際のフォルダ名は、日本時間の現時刻で`yyyymmddhhmmss_結合テスト`の形式としてください。
- エビデンスは複製したフォルダ配下にあるevidenceフォルダ配下に格納してください。
- テスト完了後は、複製したフォルダ配下のevidenceフォルダ配下にあった、`.gitkeep`ファイルは削除してください。
- もしReactのローカルサーバーが起動していなかったら、`npm run dev`コマンドを実行して起動してください。ただし、あなたが起動した場合は、テスト終了後に停止してください。
```

## 仕組み

プロジェクトルートフォルダに配置されている、`.mcp.json`ファイルにplaywright mcpの設定を記述してあるため動作することができている。今回はプロンプトだけで操作指示をしているが、実際に本番プロジェクトでやるなら、操作手順は結合テストケースを読み込ませ、必要な制御はSKILLsを別途作成するのが良いと思う。

## 各画面の説明

- ログイン(`/login`): ユーザー名3文字以上・パスワード4文字以上を入力すれば誰でもログイン可能。ログイン成功でユーザー一覧へ遷移
- ユーザー一覧(`/users`): 検索、新規追加、削除ができる。各行の「詳細」からユーザー詳細へ、「ログアウト」からログインへ遷移
- ユーザー詳細(`/users/:id`): 一覧の「詳細」から遷移。氏名・メール・役割を編集して保存、削除も可能。「一覧へ戻る」または削除でユーザー一覧へ戻る

未ログインで`/users`や`/users/:id`にアクセスすると自動的にログインへリダイレクトされる。
